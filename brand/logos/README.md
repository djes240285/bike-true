# Логотипы BikeTrue

Черновики для выбора. Букв и монограммы в знаке нет.

| Файл | Идея |
|------|------|
| `A-line-bike` | Тонкий силуэт велика, янтарь на шатуне и дуга угла |
| `B-pose-angle` | Точки суставов и угол колена, рама едва намечена |
| `C-soft-badge` | Тёмный скруглённый квадрат, лёгкий велик внутри |

У каждого варианта два файла: `.jpg` (эскиз) и `.svg` (чистая векторная версия для сайта и Telegram).

Сайт пока на старом favicon — сюда ничего не подключено, пока не выберешь.
