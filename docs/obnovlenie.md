# Как обновлять BikeTrue

Дата: 25 октября 2026.

Пуш в `main` выкладывает только сайт. Кабинет и база от пуша не переезжают.

```text
сайт     Netlify, ветка main     страницы, стили, пароль, заявка в Telegram
кабинет  Bun + MySQL, локально   Google, Яндекс, Telegram, мерки, велосипеды, разборы
```

Пока сайт закрыт общим паролем, кабинет на прод не выкладывается. На проде они открываются вместе.

## 1. Выложить сайт

```bash
git push origin main
```

Дальше на Netlify, не в терминале:

```text
сборка          bun run build
готово          зелёная сборка
проверка        приватное окно → «Сюда пока только свои»
старая вёрстка  обновить страницу
телефон         «Есть новая версия» — это кэш, не пароль и не кабинет
```

Пуш сам этого не делает:

```text
не поднимает кабинет на сервере
не применяет миграции MySQL
не копирует .env
```

Секреты живут в панели Netlify и в `.env.example` только как имена.

```text
PUBLIC_*          вшиваются в сборку → после смены нужна новая сборка
SITE_PASSWORD     читается при запросе → сборка не нужна
TELEGRAM_*        читается при запросе → сборка не нужна
PRICE_RUB         читается при запросе → сборка не нужна
```

Новый `SITE_PASSWORD` гасит старую куку пароля.

## 2. Подтянуть себе

Из корня репозитория, по порядку. Шаг пропускай, если условие в комментарии не про тебя.

```bash
git pull

# менялись package.json или bun.lockb
bun install

# в коммите есть новый файл api/drizzle/*.sql
# база берётся из DATABASE_URL в .env
bun run api:migrate

# менялись api/ или переменные кабинета в .env
# старый процесс на 8787 сначала останови
bun --env-file=.env run api

# менялись astro.config.mjs или PUBLIC_*-переменные
bun run dev

# менялся src/lib
bun test src/lib
```

Адреса:

```text
сайт     http://127.0.0.1:4321
кабинет  http://127.0.0.1:8787
```

## 3. Две куки

```text
bt_gate      общий пароль, ты и Дима     приватное окно или стереть куку
bt_session   кабинет человека            «Выйти» у имени в шапке
```

«Войти» в шапке — это кабинет. Пароль сайта спрашивается на `/enter` и только без куки `bt_gate`.
